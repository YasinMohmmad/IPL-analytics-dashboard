# 🏏 IPL Analytics Dashboard

An interactive IPL Analytics Dashboard built using **Power BI** and **Python** to analyze IPL match and player performance data.

This project focuses on transforming raw IPL datasets into meaningful visual insights through data cleaning, modeling, and dashboard creation.

---

## 📌 Project Overview

The IPL Analytics Dashboard provides insights into:

- Total Matches Played
- Total Runs Scored
- Team Winning Analysis
- Toss Decision Trends
- Top Run Scorers
- 🟧 Orange Cap Winners by Season
- 🟪 Purple Cap Winners by Season

This dashboard allows interactive exploration of IPL statistics and performance trends.
